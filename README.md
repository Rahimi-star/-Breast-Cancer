# Breast Cancer Survival Analysis with TCGA Genomic Data

This repository contains the complete code for comprehensive gene expression analysis and prognostic biomarker identification in breast cancer. Using TCGA-BRCA data and bioinformatics methods, three key genes associated with patient survival were identified.

## 🎯 Project Objectives
- Identify differentially expressed genes associated with survival
- Analyze biological pathway roles (PGR, TP53, MYC)
- Develop potential gene signatures for prognosis prediction

## 🔑 Key Findings
- Identified 3 significant genes: **RPGRIP1** (HR=0.91), **RPGRIP1L** (HR=1.20), **TP53TG1** (HR=0.82)
- TP53 pathway showed protective effects
- Sensitivity analyses confirmed result robustness
